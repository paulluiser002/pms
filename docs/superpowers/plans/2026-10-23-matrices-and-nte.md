# Indicator matrices and NTE files

Preserve the existing HRDotNet appearance and journal workflow.

1. Add a flexible reference table or numeric threshold scale to each KPI indicator. Explicitly enable scale scoring; validate scale bounds and preserve matrices in cycle snapshots.
2. Add Journal Entries / NTE Files tabs to 202 Files. HR creates drafts, edits, issues, cancels, and closes notices. Managers can read issued notices within their team; employees can read their own issued notices and submit explanations. Drafts stay HR-only.
3. Notify employees in the existing in-app notification menu upon issuance. Record read, response, cancellation, and closure events. Overdue notices stay actionable; no automatic disciplinary decision.
4. Verify permissions, lifecycle transitions, input validation, snapshot scoring, existing workflows, browser views, and packaged exports.

NTE fields: category, subject, body, explanation deadline, optional incident date and reference. Issued notice content is immutable; cancellation requires a reason, closure requires an outcome note. Dates follow the existing demo application's workflow clock. This is a local browser-persisted prototype, matching existing storage architecture.

Confirmed user decisions: both reference/scoring matrices with an explicit toggle; HR alone issues NTEs; managers have team read access.
